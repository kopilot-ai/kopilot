# Kopilot brand

## The mark: the dial

The logo is the autonomy dial itself: a rotary instrument knob with three
detent ticks, pointer turned to position 2, the moment an operator delegates
authority. It is the product's one mechanism drawn as an object.

Files:

| File | Use |
|---|---|
| `kopilot-icon.svg` | App icon, favicon, avatars, stickers (ink tile) |
| `kopilot-mark-light.svg` | Mark on light backgrounds |
| `kopilot-mark-dark.svg` | Mark on dark backgrounds |
| `kopilot-wordmark-light.svg` | Lockup on light backgrounds |
| `kopilot-wordmark-dark.svg` | Lockup on dark backgrounds |

Rules: the pointer always sits at position 2 (upper right). Never rotate,
recolor, or add a fourth tick. The dial replaces the first "o" in the
wordmark and nothing else, ever.

The brand board lives in Canva
([view](https://www.canva.com/d/dbcSuuqVMUTzsxm), `brand-board.png` here is
the export) alongside the uploaded dial assets.

## Color

| Token | Hex | Role |
|---|---|---|
| Ink | `#10141F` | Primary surface (dark-first), text on light |
| Bone | `#F4F1EA` | Light surface, text on ink |
| International Orange | `#FF4F1F` | The pointer. CTAs, gated/approval accents. One orange element per view. |
| Signal Green | `#2FBF71` | Granted / autopilot / success states only |
| Slate | `#5B6472` | Secondary text, borders, muted UI |

Orange is the aviation safety color and carries the approval story; it is an
accent, never a background. Green means authority was granted; it never
decorates.

## Type

- Display and headings: **Space Grotesk** (Google Fonts), tight tracking.
- Body: **Inter**.
- Code and CRD/API strings: **JetBrains Mono**.

The product name is lowercase `kopilot` in running text and the wordmark;
"Kopilot" only at sentence start in prose.

## Voice

Engineer to engineer. Plain verbs, real numbers, honest limits stated. No
hype, no invented users, no benchmarks we did not run.
