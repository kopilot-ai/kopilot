# Code of Conduct

Kopilot follows the [CNCF Code of Conduct](https://github.com/cncf/foundation/blob/main/code-of-conduct.md).

To report a violation, email the lead maintainer (see MAINTAINERS.md) or, if
the concern involves a maintainer, contact the CNCF Code of Conduct Committee
at conduct@cncf.io.
